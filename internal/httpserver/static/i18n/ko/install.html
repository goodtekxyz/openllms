시작하기

CLI로 계정을 등록하고 API 주소를 만든 뒤, 쓰는 도구에 Base URL과 sk-gt 키만 넣으면 됩니다.

curl -fsSL https://llms.goodtek.xyz/install.sh | bash

1. CLI 설치

Linux / macOS (amd64, arm64)

curl -fsSL https://llms.goodtek.xyz/install.sh | bash
llms --help

바이너리는 게이트웨이 /dist에서 받습니다 (GitHub 인증 불필요). 확인: llms version

2. 로그인

llms login

GitHub로 로그인하면 sk-gt 키가 저장됩니다.

3. 계정 · 라우트

llms add
llms route create
llms route key <slug>

Claude·Codex 구독, OpenAI·DeepSeek 등 API 키를 등록할 수 있습니다. 라우트를 만들면 /r/<slug>/v1 주소가 생깁니다.

4. 도구에 연결

설정값
Base URLhttps://llms.goodtek.xyz/r/<slug>/v1
API Keysk-gt-… (llms route key)
 
curl -sS https://llms.goodtek.xyz/r/<slug>/v1/chat/completions \
  -H "Authorization: Bearer sk-gt-…" \
  -H "Content-Type: application/json" \
  -d '{"model":"…","messages":[{"role":"user","content":"안녕"}]}'

웹 검색은 tools에 web_search, 이미지는 generate_image를 추가하세요. API 안내 · API 문서

5. 콘솔

터미널 대신 브라우저에서 관리하려면 콘솔을 열세요. 계정·라우트·키를 웹에서 관리할 수 있습니다.

6. 셀프호스트

클라우드 대신 직접 돌리려면 MIT 엔진 openllms를 쓰세요. SQLite·파일 시크릿, Compose 한 줄로 시작할 수 있습니다.

git clone https://github.com/goodtekxyz/openllms
cd openllms
cp deploy/oss/.env.example deploy/oss/.env   # BOOTSTRAP_TOKEN 설정
docker compose -f deploy/oss/docker-compose.yml up --build
