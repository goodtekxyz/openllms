POST https://llms.goodtek.xyz/v1/chat/completions
Authorization: Bearer sk-gt-…

익숙한 OpenAI Chat Completions 형식이에요. Claude·Codex처럼 연결해 둔 계정에 Base URL 하나로 호출하면 됩니다.

최소 요청

{
  "model": "gpt-5.4-mini",
  "messages": [
    {"role": "system", "content": "You are helpful."},
    {"role": "user", "content": "Hello"}
  ],
  "stream": true
}

도구

별도 검색/이미지 API는 없습니다. OpenAI처럼 같은 chat/completions 요청의 tools에 function tool로 넣으면 됩니다. 모델·계정이 지원하면 llms가 호스티드 웹 검색·이미지로 연결해 줘요.

클라이언트 함수동작
web_search지원되면 웹 검색
generate_image지원되면 이미지 생성
other functions클라이언트가 직접 실행하도록 전달

선택 llms 힌트

{
  "llms": {
    "web_search": {"mode": "live"},
    "session_key": "thread-abc"
  }
}
