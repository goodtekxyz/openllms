API

이렇게 호출하세요

OpenAI Chat Completions 형식 그대로입니다. 주소와 키만 맞추면 Cursor·에이전트·스크립트 모두 같은 방식입니다.

Base URL https://llms.goodtek.xyz/r/<slug>/v1 호출 POST …/chat/completions 인증 Authorization: Bearer sk-gt-…

대화

messages만 보내면 됩니다.

웹 검색

tools에 web_search를 추가하세요.

이미지

tools에 generate_image를 추가하세요.

$ curl -sS "https://llms.goodtek.xyz/r/MY_ROUTE/v1/chat/completions" \
-H "Authorization: Bearer sk-gt-…" \
-H "Content-Type: application/json" \
-d '{"model":"…","messages":[{"role":"user","content":"안녕"}]}'

자세한 내용은 API 문서를 참고하세요.

FAQ

자주 묻는 질문

llms가 뭔가요?

Claude·Codex 구독이나 API 키를 llms에 연결해 두면, 쓰는 도구에는 API 주소 하나만 넣으면 됩니다. 계정이 여러 개여도 한도에 맞게 나눠 씁니다.

어떤 도구에 붙이나요?

OpenAI 호환 Base URL을 넣는 IDE·CLI·봇·스크립트면 됩니다. Cursor, Continue, 자체 봇 등 어디든.

서버를 직접 띄워야 하나요?

필수는 아닙니다. llms.goodtek.xyz에서 바로 쓸 수 있습니다. 직접 운영하려면 openllms로 셀프호스트하세요.

콘솔은 뭐가 다른가요?

브라우저에서 계정·라우트·키를 관리합니다. 터미널 CLI와 같은 일을 웹에서 할 수 있습니다.
