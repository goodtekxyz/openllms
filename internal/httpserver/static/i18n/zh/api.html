API 文档

面向 Agent 与 OpenAI 兼容客户端的统一 API。

机器可读原文： /LLMS_API.md

端点

POST https://llms.goodtek.xyz/v1/chat/completions
Authorization: Bearer sk-gt-…
Content-Type: application/json

OpenAI 兼容的 Chat Completions。Claude、Codex 等已连接账户共用一个 Base URL。

最小请求

{
  "model": "gpt-5.4-mini",
  "messages": [
    {"role": "system", "content": "You are helpful."},
    {"role": "user", "content": "Hello"}
  ],
  "stream": true
}

工具

没有单独的搜索/图像 API。和 OpenAI 一样，在同一 chat/completions 请求的 tools 里放 function tool。上游支持时，网关会映射为托管工具。

客户端函数行为
web_search可用时映射为托管网页搜索
generate_image可用时映射为托管图像生成
other functions作为客户端执行工具透传

可选 llms 提示

{
  "llms": {
    "web_search": {"mode": "live"},
    "session_key": "thread-abc"
  }
}

响应

OpenAI chat completion 形状，外加可选 llms 扩展（account_id、provider、hosted_tools）。
