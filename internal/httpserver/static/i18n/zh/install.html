开始使用

安装 CLI，添加账户和路由，然后在工具中设置 Base URL 和 sk-gt 密钥。

curl -fsSL https://llms.goodtek.xyz/install.sh | bash

1. 安装 CLI

curl -fsSL https://llms.goodtek.xyz/install.sh | bash

2. 登录

llms login

3. 账户与路由

llms add
llms route create
llms route key <slug>

4. 接入工具

Base URL: https://llms.goodtek.xyz/r/<slug>/v1 · API 指南

5. 控制台

在控制台用浏览器管理。

6. 自托管

自行部署请用 openllms（MIT）。

docker compose -f deploy/oss/docker-compose.yml up --build
