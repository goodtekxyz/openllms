将 Claude、Codex 订阅和 API 密钥连接到 llms。你的工具只需一个地址。对话、网页搜索、图片也使用同一 API。

开始

三步即可

  1. 01

    连接账户

    添加 Claude、Codex 订阅或 API 密钥。

  2. 02

    创建地址

    创建路由，获得 /r/…/v1 地址。

  3. 03

    接入工具

    设置 Base URL 和 sk-gt 密钥。

FAQ

常见问题

llms 是什么？

连接订阅或 API 密钥后，工具只需一个 URL。多个账户会自动分配。

支持哪些工具？

任何支持 OpenAI 兼容 Base URL 的 IDE、CLI、机器人。

需要自建服务器吗？

不是必须。可直接使用 llms.goodtek.xyz。若要自建，请看 openllms。
