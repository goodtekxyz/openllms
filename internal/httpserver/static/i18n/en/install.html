Get started

Install once, add accounts, create a route, then set Base URL and sk-gt in your tool.

curl -fsSL https://llms.goodtek.xyz/install.sh | bash

1. Install CLI

curl -fsSL https://llms.goodtek.xyz/install.sh | bash
llms --help

2. Log in

llms login

3. Accounts & routes

llms add
llms route create
llms route key <slug>

4. Connect your tool

SettingValue
Base URLhttps://llms.goodtek.xyz/r/<slug>/v1
API Keysk-gt-…

Add web_search or generate_image in tools for search and images. API guide · API docs

5. Console

Prefer the browser? Manage everything in the console.

6. Self-host

Want your own box? Use MIT openllms — SQLite, file secrets, one Compose file.

git clone https://github.com/goodtekxyz/openllms
cd openllms
cp deploy/oss/.env.example deploy/oss/.env   # set BOOTSTRAP_TOKEN
docker compose -f deploy/oss/docker-compose.yml up --build
