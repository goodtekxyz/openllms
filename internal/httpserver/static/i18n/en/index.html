FAQ

Questions

What is llms?

Connect Claude, Codex, or API keys once. Your tools use one URL. Multiple accounts are routed for you.

What can I connect?

Any tool that accepts an OpenAI-compatible Base URL — Cursor, Continue, CLI, bots, scripts.

Do I need to self-host?

No. Use llms.goodtek.xyz directly. Prefer your own box? Use openllms.

What is the console?

Manage accounts, routes, and keys in the browser — same as the CLI, in a web app.
