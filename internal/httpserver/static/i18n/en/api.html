Endpoint

POST https://llms.goodtek.xyz/v1/chat/completions
Authorization: Bearer sk-gt-…
Content-Type: application/json

OpenAI-compatible Chat Completions. One Base URL for Claude, Codex, and other connected accounts.

Minimal request

{
  "model": "gpt-5.4-mini",
  "messages": [
    {"role": "system", "content": "You are helpful."},
    {"role": "user", "content": "Hello"}
  ],
  "stream": true
}

Tools

No separate search/image API. Same as OpenAI: put function tools on the same chat/completions request. When upstream supports it, the gateway maps them to hosted tools.

Client functionBehavior
web_searchHosted web search when available
generate_imageHosted image generation when available
other functionsPassed through as client-executed tools

Optional llms hints

{
  "llms": {
    "web_search": {"mode": "live"},
    "session_key": "thread-abc"
  }
}

Response

OpenAI chat completion shape, plus optional llms extensions (account_id, provider, hosted_tools).
