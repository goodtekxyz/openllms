API ドキュメント

エージェントと OpenAI 互換クライアント向けの統合 API。

機械可読の原文: /LLMS_API.md

エンドポイント

POST https://llms.goodtek.xyz/v1/chat/completions
Authorization: Bearer sk-gt-…
Content-Type: application/json

OpenAI 互換の Chat Completions。Claude・Codex など接続済みアカウントへ Base URL ひとつで呼び出せます。

最小リクエスト

{
  "model": "gpt-5.4-mini",
  "messages": [
    {"role": "system", "content": "You are helpful."},
    {"role": "user", "content": "Hello"}
  ],
  "stream": true
}

ツール

検索・画像用の別 API はありません。OpenAI と同じく、同じ chat/completions リクエストの tools に function tool を入れます。対応していればゲートウェイがホスト済みツールへマップします。

クライアント関数動作
web_search利用可能な場合はホスト済み Web 検索
generate_image利用可能な場合はホスト済み画像生成
other functionsクライアント実行ツールとして通過

任意の llms ヒント

{
  "llms": {
    "web_search": {"mode": "live"},
    "session_key": "thread-abc"
  }
}

レスポンス

OpenAI chat completion 形式に加え、任意の llms 拡張（account_id、provider、hosted_tools）。
