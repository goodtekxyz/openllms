はじめる

CLI を入れてアカウントとルートを作り、Base URL と sk-gt を設定します。

curl -fsSL https://llms.goodtek.xyz/install.sh | bash

1. CLI インストール

curl -fsSL https://llms.goodtek.xyz/install.sh | bash

2. ログイン

llms login

3. アカウント・ルート

llms add
llms route create
llms route key <slug>

4. ツールに接続

Base URL: https://llms.goodtek.xyz/r/<slug>/v1 · API ガイド

5. コンソール

コンソールでブラウザ管理もできます。

6. セルフホスト

自分で動かすなら openllms（MIT）。

docker compose -f deploy/oss/docker-compose.yml up --build
