FAQ

よくある質問

llms とは？

サブスクや API キーを接続すると、ツールには URL ひとつだけ設定すれば OK です。

どんなツールに使える？

OpenAI 互換 Base URL を受け付ける IDE・CLI・ボットならどれでも。

自前ホストは必要？

必須ではありません。llms.goodtek.xyz をそのまま使えます。自分で運用するなら openllms へ。
